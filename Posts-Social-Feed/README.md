
# VYBE – Posts & Social Feed

## Project Description
Posts & Social Feed is a module of the VYBE social networking application.

## Technologies
- HTML5
- CSS3
- JavaScript
- Python Flask
- MySQL
- Git and GitHub

## Features
1. Create photo and video posts.
2. Write captions.
3. View posts from followed users.
4. Edit own posts.
5. Delete own posts.
6. Like and unlike posts.
7. Add and view comments.
8. Share posts.

## Database
Database Name: vybe_social_feed

Tables:
- users
- follows
- posts
- likes
- comments

## Installation

Install dependencies:

pip install -r requirements.txt

Run the database/schema.sql file in MySQL.

Start the backend:

python app.py

Open in browser:

http://127.0.0.1:5000

## Team Integration
This module will be integrated with the VYBE Authentication and User Profile modules.
The current demo user ID will be replaced with the authenticated user ID.
